## Найдено независимой проверкой кода, отложено (не критично)

- [ ] Действие `open` подставляет значения как есть для файлов и папок: присланное снаружи значение может
      указать на любой файл или протокол. Ограничить папкой проекта.
- [ ] Нельзя написать в команде буквальное `{слово}` (например, `git rev-list @{u}..HEAD`) — нужен способ
      экранирования.
- [ ] Вывод действия копится в памяти и попадает в лог только по завершении (до 15 минут). Писать сразу.
- [ ] Файл состояния проекта меняется из нескольких потоков без общей блокировки.
- [ ] Если убрать или переименовать работающий сервер в `panel.json`, его процесс остаётся без присмотра.
- [ ] Поиск корня проекта и чтение файла идут в потоке окон: зависшая сетевая папка «заморозит» все панели.
- [ ] Если браузерный движок не запустился, панель остаётся пустой до перезапуска программы (нет повторной
      попытки).
- [ ] `check` умеет печатать «последнюю ошибку панели», но страница её никогда не сообщает.
- [ ] Разрешённые в значениях символы включают `-` и `/` в начале: значение может стать ключом команды.
- [ ] Серверы в Docker или WSL без своей команды `stop` показываются как «порт занят другой программой».

## Последствия принятых решений (может, захочешь иначе)

- Клик по кнопке панели, когда впереди другая программа, выполняет действие, но Проводник вперёд не выводит.
  Раньше выводил — и из-за этого закрывалось меню и отбирался фокус у чужого окна.
- `explorer-panel untrust` «забывает» папку (панель спросит снова), а не запрещает её.
- Сквозные проверки на время прогона останавливают установленную программу (панели пропадают на минуту).
- Первая версия установщика записала пользовательский PATH обычной строкой, раскрыв переменные вида
  `%USERPROFILE%`. Тип значения исправлен, установщик исправлен; сами записи остались в раскрытом виде
  (работают так же).
- В коммитах этого репозитория — адрес GitHub-noreply вместо личного (локальная настройка git этого
  репозитория). Вернуть обычный адрес: `git config --unset user.email`.
